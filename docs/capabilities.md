# Capability ledger

The step `docs/knowledge-retention-plan.md` asked for: before building anything
that overlaps an existing capability, write down what exists and why it is not
being used. One row per capability; the "used by" column is the audit trail.

## Caches, bundles and export (opened for ADR-0084)

| Capability | Where | Used by | Why / why not |
|---|---|---|---|
| Erosion cache `cache/terrain/<hash>.bin` | `procgen/terrain_field.cpp:618` | terrain load | the precedent: FNV-1a over sampled inputs + params + tag, raw floats, `RT_NOCACHE` |
| Cloud-noise cache `cache/clouds/<hash>.bin` | `renderer/metal/cloud_noise.h:265` | sky | same shape, descriptor string with a version tag |
| Level bundle `Bundle`/`BundleWriter` | `engine/bundle/bundle.h` | loader, `rt_bake`, editor | one file, aligned mmap-able sections, JSON TOC, manifest as commit marker; general — no producer knowledge |
| Producers, keys, bake, obtain, prune | `engine/bundle/bake.h` | loader, `rt_bake`, editor | content keys + code tags, copy-forward of unchanged producers, `RT_NOCACHE`/`RT_BUNDLE_*` knobs; `pruneBundles` keeps the newest per level |
| Codecs `PackedMesh`, height grid, road graphs, rings | `engine/bundle/codecs.h` | city producer, GLB view | float32 packed meshes; the cold path packs too (byte-identical cold/warm) |
| Lot codecs | `procgen/city/lot_cache.h` | lots producer, loader | `NetLotResult` to sections — every `BuildingParams` field by hand, parts per render cell, `kLotsFormatVersion` |
| Lot-pass setup | `engine/lot_grow_setup.h` | loader `growCityLots`, lots producer | one derivation of `LotParams`/`EdgeBlockParams`/books/spawn from a level |
| Build identity `build_info.h` | generated by CMake | logs, `info`, manifests | `git describe --dirty` at configure |
| GLB writer | `engine/glb_export.h` | bundle view (and `lanelab_tool`, next merge) | TANGENT + COLOR_0 + extras added on the move |
| Bundle → GLB view | `engine/bundle/bundle_glb.h` | `rt_bake --glb`, editor | per material or per cell from section names alone |
| `MeshBuilder::chunkByCell` | `engine/mesh_builder.h` (was `level_loader.cpp`) | loader chunking, city producer | a bundle cell is a render cell |

The road capabilities this ledger opened for (ADR-0083, lanelab) and the two bundle producers that
read them — `city` and `lots` — arrive with the lanelab library in the next merge.
