# Credits

Everything the project did not make itself: code we link, data we ship, and the outside material we measured
against. The project's own code and assets are under [LICENSE](LICENSE) (MIT). Procedural content (terrain,
cities, buildings, vehicles, trees, sounds, textures, street and place names) is generated by the engine and
needs no credit.

**Rule:** anything made by someone else that enters the repo, the build, or a calibration gets a line here in the
same change, with its source, author and licence. That includes CC0 and public-domain work, where the licence
does not require it. "Measured against" counts too.

## Methods named in the code

Published techniques we implemented. These are courtesy credits, not licence obligations:
- ACES filmic fit (Stephen Hill)
- AgX minimal fit (Benjamin Wrensch, after Troy Sobotka)
- sky and atmosphere models (Hillaire; Bruneton)
- interleaved gradient noise (Jimenez)
- PCG hash (Jarzynski & Olano)
- multiple-scattering octaves for clouds (Wrenninge)
- Möller-Trumbore ray-triangle intersection
- SplitMix
- Chaikin corner cutting
- SAE J1100 / J826 occupant and vehicle dimensions
