The Procedural Toolkit

The city is the showpiece, but it's assembled from a handful of general-purpose generators that run throughout the engine. Trees, rocks, terrain, buildings, and materials all come from the same idea: a generator is data, and complexity is grown by composing small operations rather than authoring assets by hand (ADR-0022). Here's the toolkit.

L-systems — grammars that grow structure

Parametric L-systemsADR-0030 · 0033

An L-system is a rewriting grammar: start from an axiom string and repeatedly replace symbols by their productions. This engine's is parametric — each symbol carries numeric parameters and productions compute the successors' parameters with real expressions (branch length falls off, angles jitter), so one compact ruleset yields endlessly varied, non-repeating structure.

A turtle interpreter walks the rewritten string — F draws forward, + − turn, [ ] push/pop a branch — and emits a Skeleton: a shared value type (a tree of segments with radii) that different consumers attach meaning to. The grammar doesn't know whether it's growing an oak or a mountain.

powers → trees & foliage · branching mountain ridge networks

Botany — from skeleton to a leafy tree

Generalized-cylinder branches + alpha leaf cardsADR-0029

The tree generator grows an L-system skeleton, then skins it: each branch becomes a generalized cylinder tapering from trunk to twig, and where branches meet, an SDF pass fuses the joints into one continuous surface instead of intersecting tubes. Leaves are alpha-cut cards clustered at the twig tips; bark and leaf textures are generated procedurally too. The result is a single mesh (bark) plus a cutout-foliage mesh, collidable and instanced across a forest.

powers → the hero trees · street trees on every green lot

SDF — the modeling kernel

Signed distance fieldsADR-0021 · 0029

A signed distance field is just a function of position: negative inside, positive outside, zero on the surface. Because it's a function, fields compose by composing functions — union is a min, intersection a max, and a smooth-min blends two shapes into one seamless surface. It's the in-house, robust analog of a B-rep modeling kernel: self-intersecting parts fuse instead of leaving cracks, which is exactly what welded L-system branches (and blobby rocks) need. Surfaces are polygonized to a mesh when a solid is required.

powers → branch fusion · procedural rocks · blended organic forms

The mesh-op library — modeling ops as code

lathe · column · steps · portico · rotunda

On top of the base mesh builder (boxes, cylinders, cones, quads, triangle-soup append) sits a small library of higher-level operations — the same primitives a modeling package gives you, callable from C++ and from Lua as mesh.lathe. The keystone is lathe: revolve a 2-D profile around an axis to make any turned form. From it:

  • column — plinth, base rings, an entasis (subtly bulged) shaft, capital, and abacus.
  • entranceSteps — a porch platform with descending treads.
  • portico — steps + a linear array of columns + an entablature beam + a pediment.
  • rotunda — a drum + a radial array of columns + an entablature ring + a lathed dome and cupola.

A civic portico isn't a bespoke model — it's steps, an array of lathed columns, a beam, and a triangle. The city's capitol dome is one rotunda call.

Noise — the texture of nature

Gradient noise, fBm, and domain warp

A seeded, deterministic gradient-noise field (improved Perlin) underlies anything that needs organic variation. Octaves sum into fractal Brownian motion for rolling hills; a domain warp (feeding noise back into its own coordinates) bends regular patterns into meandering ones. On top of this, the terrain builds a ridged-multifractal mountain layer — concentrating detail on sharp crests while valleys stay smooth, the difference between uniform bumps and real peaks. Same seed, same field, every run.

powers → terrain relief · material mottle · scatter placement · street curviness

Terrain — heightfield, LOD, erosion, conforming

Analytic heightfield with CDLOD morphingADR-0036 · 0044

The ground is a single analytic height function — the mesh, the physics collider, and every placement query all read the same surface, so nothing ever disagrees about where the ground is. A mountain layer (masked ridged-multifractal, or a spine-driven range compiled from an L-system ridge network) adds relief. CDLOD streams it as a camera-relative quadtree with vertex morphing so distant tiles coarsen without popping, and an optional droplet erosion pass carves drainage detail.

Crucially, terrain takes cut/fill footprints back from the city: roads carve a graded corridor and buildings stamp flat pads, so the town meets the ground instead of poking through it (see how the city is built).

powers → the world the city stands on · open-terrain scenes

Procedural materials — analytic PBR surfaces

A surface library baked to tiling texturesADR-0039 · 0043

Every surface — brick, concrete, stucco, roof tile, shingle, corrugated metal, asphalt, pavement, cobblestone, wood siding — is an analytic function composed from a small 2-D field vocabulary (grids, mortar bands, mottle, speckle). Each one yields albedo, height, and roughness at any point; the height gradient bakes a normal map. These are rendered once per surface class into shared, world-tiling PBR texture sets, so a whole district of a thousand buildings draws as a handful of textured meshes, lit as real physically-based materials rather than flat colour. Road lane paint is composited straight from the carriageway's own mesh UVs — no z-fighting, crisp at any distance.

powers → every building facade · roads & sidewalks · roofs

How it all composes

None of these stands alone — the city is what happens when they run together. Noise shapes the terrain; L-systems grow the trees on it and the ridges behind it; the road grammar and the building shape grammar (mesh-ops + the material library) fill the streets; SDF fuses the organic joints; and the whole thing conforms to the ground it sits on. Every piece is deterministic and unit-tested headless, so the same seed always rebuilds the same world.
