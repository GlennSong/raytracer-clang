# Fonts

- `Overpass-Bold.ttf` -- Overpass, the open typeface derived from the US highway
  signage alphabet (FHWA "Highway Gothic"), by Delve Withrington / Red Hat.
  SIL Open Font License 1.1 (`OFL.txt`). From
  https://github.com/RedHatOfficial/Overpass at c580d28 (`fonts/ttf/Overpass-Bold.ttf`).
  Used for street name signs and in-game text (engine/text/font.h).
- `Pacifico-Regular.ttf` -- Pacifico, a brush script by Vernon Adams, Jacques Le Bailly, Botjo Nikoltchev and
  Ani Petrova. SIL Open Font License 1.1 (`OFL-Pacifico.txt`). From https://github.com/google/fonts at 8b0a1d0
  (`ofl/pacifico/Pacifico-Regular.ttf`). The bars' neon script signs (engine/text/font.h neonFont).
- `TiltNeon.ttf` -- Tilt Neon, a face drawn as bent glass tube, by Andy Clymer. SIL Open Font License 1.1
  (`OFL-TiltNeon.txt`). From https://github.com/google/fonts at 8b0a1d0 (`ofl/tiltneon/TiltNeon[XROT,YROT].ttf`,
  the variable font, used at its default instance). The clubs' neon signs and the OPEN signs (tubeFont).
